What this means

    Equity curves (cumulative R)

    Cumulative R per trading day. 1R is the planned risk per trade (about 1% of the account). The dashed line marks the in-sample / out-of-sample split. The walk-forward line starts after its first 24-month training window.

    R by year

    Total R per calendar year for each featured config.

    Parameter sensitivity

    For each parameter value, the average R per trade across every grid config that uses it, in-sample vs out-of-sample. A value that helps in both periods is a pattern; one that only helps in-sample is likely noise.
